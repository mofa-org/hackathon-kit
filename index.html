Three Steps to Launch

From zero to a live hackathon site in under ten minutes.

Fork the Repo

Clone or fork hackathon-kit to your own GitHub account.

Configure Your Event

Edit the YAML config and .env with your event details and Supabase keys.

Deploy

One-click deploy to Vercel or Netlify — or self-host anywhere.

Built with Modern Tech

Vue 3 TypeScript Vite Tailwind CSS Supabase

Deploy in One Click

Pick your platform and go live instantly.

$ git clone https://github.com/mofa-org/hackathon-kit.git
$ cd hackathon-kit && cp .env.example .env
$ npm install && npm run dev
